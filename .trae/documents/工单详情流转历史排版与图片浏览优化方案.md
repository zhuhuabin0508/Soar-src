# 工单详情·流转历史排版与图片浏览优化方案

## Summary

流转历史时间线卡片中，富文本处置意见粘贴多图时卡片高度失控（N 张图 × 240px 纵向堆叠），且放大预览（Lightbox）不支持多图切换，看另一张图必须"关闭 → 再双击"。本方案对 `TicketRichText.jsx` 通用组件做两处增强：

1. **RichTextView 图片布局分级**：少量图（≤3 张）保持内联大图但限高 160px；多图（≥4 张）自动转为九宫格缩略图网格，卡片高度从 N×240px 降至约 ⌈N/5⌉×100px。
2. **Lightbox 升级为多图画廊**：左右箭头按钮 + ←/→ 键盘切换 + "2 / 9" 计数 + 底部缩略图导航条；展示态缩略图改为**单击打开**（编辑器内保留双击防误触）。

不改折叠策略（用户决策：不加"展开/收起"）、不改数据层（markdown 图片引用 `![名称](url)` 格式与存量数据完全兼容）、不改后端。

## Proposed Changes

### 改动 1：Lightbox 多图画廊化（TicketRichText.jsx）

**新 API**：

```jsx
// images: [{ src, name }]；index: 当前索引；onIndex(i)：切换回调；onClose()
export function Lightbox({ images, index, onIndex, onClose })
```

行为规格：

- **键盘**：`←`/`→` 切换（**循环**，末张按 → 回到首张）；`Esc` 关闭（保留现有监听）
- **箭头按钮**：屏幕左右两侧垂直居中 `ChevronLeft`/`ChevronRight`（`lucide-react` 已在用），白色半透明、hover 提亮；触达区域加大（`p-4` 内 padding）
- **计数器**：底部居中显示 `当前 / 总数`（如 `2 / 9`），`text-white/70`
- **底部缩略图导航条**：`max-w-[90vw]` 横向可滚动的 `h-12` 缩略图行；当前张用 `ring-2 ring-white/80` 高亮；点击直接跳转；容器自动滚动到当前缩略图（`scrollIntoView({ block:'nearest' })` 或手动 scrollLeft 计算）
- **关闭交互不变**：点击空白、双击图片、Esc 关闭（存量习惯保留）；图片仍 `max-h-[78vh] max-w-[90vw] object-contain`
- **单张图（images.length === 1）**：不渲染箭头/计数/缩略图条（与旧版视觉一致）
- 提示文案改为：`点击 ←/→ 或双击图片切换；点击空白处或 Esc 关闭`（单图时保留原文案语义）

文件头注释（第 1-7 行）同步更新为画廊描述。

### 改动 2：RichTextView 图片布局分级 + 单击打开（TicketRichText.jsx）

解析逻辑保持现有 `IMG_MD_RE` matchAll 结构，改动渲染分支：

```jsx
const images = matches.map((m) => ({ src: attachmentUrl(m[2]), name: m[1] || '图片' }))
```

- **文本段**：仍按原顺序以 `whitespace-pre-wrap break-all` 的 span 渲染（含图片前后夹文场景）
- **images.length ≤ 3**：每张图按现样式内联渲染，但 `max-h-60` → **`max-h-40`**（240px→160px），`object-contain` 保持不裁切
- **images.length ≥ 4**：图片不再内联，文本段全部先渲染，随后渲染一个 `flex flex-wrap gap-2` 网格：
  - 缩略图 `h-24 w-24`（96px）`object-cover cursor-zoom-in rounded-md border border-border hover:border-primary/50`，`loading="lazy"`
  - **超过 9 张**：默认只显示前 9 张 + 1 个 `+N` 溢出块（同尺寸、`bg-muted text-muted-foreground`，显示 `+3`），点击溢出块后本地 state `showAll=true` 展示全部；文本提示剩余张数
  - 网格前加一行小标题（可选）：`截图 · N 张`，`text-xs text-muted-foreground`——仅多图模式显示
- **打开方式**：缩略图/内联图 **`onClick` 单击**打开 Lightbox（state 记 `{ index }`，Lightbox 传入完整 images 数组）；移除 onDoubleClick 避免"单击+双击"双路径
- state 从 `{ src, name }` 改为 `{ index }`，Lightbox 数据由 images 数组派生

### 改动 3：RichEditable 编辑态适配（TicketRichText.jsx）

编辑态布局不动（框内图仍 `max-h-60` 内联、所见即所得），仅两处适配：

- `handleDblClick`（254-262 行）里 `setLightbox({ src, name })` → `setLightbox({ index: 0 })` + `images=[{ src, name }]`（编辑器只有单张上下文，Lightbox 走单图模式，无箭头）
- 底部渲染调用点（281 行）同步新 API

## Assumptions & Decisions

- 用户已确认：**少量大图 + 多图网格**、**不加折叠**、**Lightbox 键盘+箭头+计数+缩略图条**
- 展示态单击打开、编辑态保留双击打开（防编辑误触放大）；切换为循环模式
- `object-cover`（裁切填满 96px 方块）用于多图缩略图——与 IM 九宫格惯例一致；≤3 张的内联大图保持 `object-contain` 不裁切
- 不动 FeedbackAdmin 本地 Lightbox、不动后端与数据格式、不动 `canonicalAttachUrl` 安全校验链路
- `RichTextView`/`Lightbox` 仅在本文件内被引用（已核实），API 可直接重构，无外部兼容负担
