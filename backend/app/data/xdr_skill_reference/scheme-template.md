# 调用方案格式模板

需求分析器输出调用方案时，严格按以下格式生成。

## 单接口方案

```markdown

### 方案类型：单接口调用

### 调用接口
- **接口路径**：{HTTP方法} {完整路径，如 /api/xdr/v1/alerts/list}
- **接口描述**：{一句话描述}

### 完整请求参数
```json
{根据需求填充了具体值的完整请求JSON，每个字段都有注释说明}
```

### 完整返回值结构

#### 响应结构
| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | string | 响应码，成功时为 "Success" |
| message | string | 响应消息 |
| data | {data类型} | 响应数据 |

#### data 结构说明
| 参数名 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
{data 层的所有字段}

#### item 元素结构说明
{按信息类别分组，列出每个字段，含类型、说明、枚举值说明、取值范围、示例值}

**枚举字段格式要求**：当返回值字段为枚举类型时，增加"枚举值说明"列：
- 从 Java 枚举类提取的字段：`{枚举类名}，参考 enum-dictionary.md。中文：值1/名称1, 值2/名称2, ...；国际版：值1/值2/...`
- 动态分类字段（无法从源码提取）：`参考 enum-dictionary-pending.md`。如 pending 文件已填写则附简要对照

**示例**：
| 字段名 | 类型 | 说明 | 枚举值说明 | 取值范围 | 示例值 |
|--------|------|------|-----------|----------|--------|
| whiteStatus | String | 加白状态 | WhiteStatusEnum，参考enum-dictionary.md。中文：0/未加白, 1/已加白, 2/部分加白；国际版：0/1/2 | 中文："0"~"2"；国际版：0~2 | "未加白" |
| dealStatus | Integer | 处置状态 | TMGIncidentDealStatusEnum，参考enum-dictionary.md。0/待处置, 10/处置中, 20/已通告, 30/已防护, 40/已处置, 50/挂起, 60/接受风险, 70/已遏制, 80/已忽略。**注意：入参接受 TMG 0-80，不是内部 IncidentDealStatusEnum 1-6** | 0~80 | 40 |
| moduleType | Integer | 攻击类型一级分类 | 参考enum-dictionary-pending.md | 配置数据 | 1 |

{对嵌套结构，展开子结构说明表格}

```

### 使用注意事项
{从接口文档的注意事项中摘取与当前需求相关的条目}
```
